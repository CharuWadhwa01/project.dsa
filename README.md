🐭 Rat in a Maze – Backtracking Algorithm
📌 Project Overview
This project demonstrates the classic Rat in a Maze problem solved using backtracking. The goal is to find a valid path for a rat to move from the top-left corner to the bottom-right corner of a maze represented by a 2D grid. The rat can only move through cells marked as 1 (path), avoiding cells marked as 0 (walls or obstacles).

🚀 Features
- Solves maze using recursive backtracking.
- Supports custom maze sizes.
- Prints one valid path (can be extended to find all paths).
- Clear console output showing the final solution path.
- Written in C++.
